# LCA / EPD Adapter

Status: **planned / not implemented in v0.1**.

The adapter will normalize declared lifecycle-assessment and environmental-product-declaration factors into ProofGrid evidence inputs.

Rules:

- every factor must retain its source and declared unit;
- dataset version and geography should be retained when known;
- system boundary and lifecycle modules must not be silently mixed;
- missing or incompatible units must fail closed or require explicit review;
- demonstration factors must be clearly marked fictional;
- professional or regulatory conclusions require the appropriate qualified review.

The v0.1 sample factors are fictional and exist only to test deterministic calculation and provenance.
