# Minimal Baseline

Use this baseline in comparative evaluations:

```text
Transform the supplied source request into a clear, self-contained prompt.
Preserve explicit requirements and constraints. Do not invent facts, tools,
authority, evidence, or completed actions. Define the required output and
state material assumptions. Return only the final prompt.

SOURCE REQUEST:
[insert source]
```

The minimal baseline tests whether PromptOS modules add measurable value beyond a compact direct instruction. PromptOS should not advance merely because it is more elaborate.
