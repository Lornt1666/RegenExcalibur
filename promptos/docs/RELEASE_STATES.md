# Release States

## ARCHITECTURE SPECIFICATION COMPLETE

The architecture and requirements are documented; executable implementation is not yet established.

## IMPLEMENTATION READY

A qualified implementation team can proceed without unresolved critical design gaps.

## IMPLEMENTED — EVALUATION PENDING

Executable source exists, but required automated or independent evaluation evidence remains incomplete.

## VERIFIED RELEASE CANDIDATE

Configured automated checks and independent semantic release gates pass for the frozen candidate.

## RELEASED

The owner has reviewed the evidence, selected licence and distribution terms, and approved the exact release artifact.

## BLOCKED

A named critical dependency, authority, safety issue, failed gate, or missing input prevents the requested state.

PromptOS v4.0 RC1 currently occupies `IMPLEMENTED — EVALUATION PENDING`.
