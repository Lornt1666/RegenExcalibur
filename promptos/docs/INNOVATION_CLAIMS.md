# Innovation and Superiority Claims

Allowed novelty classes:

- known improvement;
- original synthesis;
- candidate breakthrough;
- no materially equivalent prior application found within the searched scope;
- prior-art-checked novelty;
- verified breakthrough.

Allowed superiority classes:

- improvement target;
- designed to outperform named comparators;
- outperforms evaluated comparators;
- candidate category leader;
- verified category leader within a defined scope.

Every stronger class requires stronger evidence. Absolute “never before” and “better than everything” statements are not accepted without a sufficiently defined and supported scope.
