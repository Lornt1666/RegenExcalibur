# Review Order

Review the pull request in this sequence:

1. Constitution and requirement registry.
2. Core request/route/compile/validate implementation.
3. Runtime module and adapter resource.
4. JSON schemas.
5. Unit and conformance tests.
6. Security model.
7. Evaluation boundary.
8. CI and wheel smoke.
9. Release manifest and checklist.
10. Licence and owner decision gates.

This order evaluates governing requirements before implementation details and implementation before release claims.
