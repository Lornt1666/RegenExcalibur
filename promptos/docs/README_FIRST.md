# Read This First

PromptOS RC1 is a reviewable implementation, not a declaration of perfection.

Start with:

1. `README.md`
2. `docs/ARCHITECTURE.md`
3. `docs/SECURITY.md`
4. `docs/EVALUATION.md`
5. `docs/STATUS.md`
6. `releases/v4.0.0-rc1/RELEASE_CHECKLIST.md`

Run:

```bash
cd promptos
make verify
```

Then inspect the branch CI receipts before changing the release state.
