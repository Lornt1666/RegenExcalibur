# v3.2 Baseline Use

The normalized constitution is the reference for v3.2 requirements, but a baseline evaluation should also retain the exact v3.2 prompt text used in each run, its hash, target model, settings, and output.

Do not silently edit the v3.2 baseline after observing PromptOS results. Any correction creates a new baseline version and requires a new identifier.

The comparison question is not whether v4.0 sounds more advanced. It is whether the compiled runtime produces higher task quality, stronger hard-gate compliance, and lower context cost on the same cases.
