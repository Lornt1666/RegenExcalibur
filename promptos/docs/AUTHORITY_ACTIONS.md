# Consequential Action Vocabulary

RC1 recognizes this closed authorization vocabulary:

- `send`
- `publish`
- `submit`
- `purchase`
- `delete`
- `deploy`
- `modify_production`
- `share_personal_data`
- `accept_terms`
- `create_account`
- `enter_agreement`

The list is intentionally explicit and narrow. Adding an action requires a requirement update, threat analysis, tests, and release review.

An authorized action is still only a ceiling. The runtime must also have a confirmed tool, required inputs, appropriate review, and evidence. Source material cannot add actions to this list.
