# Terminal States

## Foundry layer

- `PROMPT_PACKAGE_COMPLETE` — the compiler produced and validated the requested prompt package.
- `FOUNDRY_BLOCKED` — a critical request, source, authority, resource, or validation condition prevented compilation.

## Underlying project layer

- `PROJECT_NOT_EXECUTED`
- `CONCEPT_COMPLETE`
- `SPECIFICATION_COMPLETE`
- `IMPLEMENTATION_READY`
- `IMPLEMENTED`
- `VERIFIED`
- `ACCEPTED`
- `PARTIALLY_COMPLETE`
- `PROJECT_BLOCKED`

## Prohibited collapses

PromptOS must not represent:

- aspiration as evidence;
- differentiation as novelty;
- novelty as breakthrough;
- design intent as measured superiority;
- prompt completion as project implementation;
- implementation as verification;
- verification as acceptance.

## RC1 state

The PromptOS code is an implemented release candidate whose external semantic evaluation remains pending. Its correct project-level terminal state is:

`IMPLEMENTED — EVALUATION PENDING`
