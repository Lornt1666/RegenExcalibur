## v3.2 migration

- Monolithic global rules → compact universal kernel.
- Complete operation catalogue → exactly one selected operation module.
- Complete disciplinary catalogue → conditional domain modules.
- Unspecified AUTO behaviour → ordered deterministic router.
- Prose-only task interpretation → inspectable PIR.
- Untrusted prompt text → escaped JSON source plus SHA-256 provenance.
- General autonomy language → exact action allowlist.
- Self-issued quality claims → deterministic, model, and human evidence gates.
- Infinite evolution risk → one-to-five bounded passes, default three.
- Generic completion claim → separate prompt, implementation, verification, and acceptance states.
