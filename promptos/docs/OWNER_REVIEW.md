# Owner Review Gate

Before merge or release, the owner should review:

- whether the normalized v3.2 constitution preserves the intended governance;
- whether `Lornt1666/RegenExcalibur` is the correct long-term repository location;
- licence selection;
- branch CI receipts;
- external evaluation plan and budget;
- permitted model providers and data handling;
- final release name and attribution;
- whether PromptOS remains a standalone subtree or becomes its own repository.

Merge is not automatic. RC1 is intentionally submitted as a draft pull request for review.
