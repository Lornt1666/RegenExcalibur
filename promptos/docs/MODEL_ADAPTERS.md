# Model Adapters

## generic-reasoning

Direct instructions, explicit delimiters, precise end state, proportionate detail, no demand for private chain-of-thought, zero-shot by default.

## openai-reasoning

Straightforward instruction language, clearly delimited data, explicit validation conditions, structured output where supported, no forced chain-of-thought, examples only when evaluation shows value.

## fast-model

Short sentences, closed enumerations, few active modules, concise examples, rigid output format, critical constraints adjacent to output.

## local-small-model

Minimal nesting, one operation, few domain modules, compact glossary, numbered steps, simple conditions, fixed schema, no reliance on distant cross-references.

Adapters alter presentation conventions. They do not weaken provider-neutral requirements for truthfulness, authority, evidence, or completion states.
