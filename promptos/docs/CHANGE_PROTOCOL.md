# Prompt Change Protocol

Every accepted prompt-system change must record:

- failure ID;
- affected case(s);
- affected requirement ID;
- proposed minimal change;
- predicted effect;
- deterministic results;
- semantic results where applicable;
- regressions;
- context/latency/cost change;
- retain or reject decision;
- reviewer.

Changes without a demonstrated problem are architectural proposals, not automatic improvements.
