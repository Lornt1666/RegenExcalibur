# No-Infinite-Recursion Invariant

PromptOS permits one to five bounded refinement passes, default three.

A pass must identify:

1. an observed material defect;
2. the requirement affected;
3. the smallest proposed correction;
4. the evaluation used;
5. any regression;
6. the retain/reject decision.

Refinement stops when all critical gates pass, another pass would only change style, added complexity would exceed value, remaining work is outside scope, or a blocker requires new data, tools, authority, model capability, or human policy.

The existence of another imaginable enhancement is not evidence that the current defined scope is incomplete.
