# ProofGrid v2.4 — Uncovered Inventory Remediation Readiness

This gate creates a deterministic successor revision of the accepted v2.3 uncovered IFC element.

The successor adds:

- one explicit material association;
- one declared mass quantity;
- exact STEP numeric-token retention;
- canonical Decimal quantity authority;
- predecessor/successor source provenance.

The result stops at `READY_FOR_EXPLICIT_MAPPING`.

It deliberately does **not** perform environmental mapping, factor selection, impact calculation, coverage promotion, whole-building completeness, scientific validation, professional review, or certification.
