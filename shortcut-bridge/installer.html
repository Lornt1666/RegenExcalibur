Install 1JGM Edge Operator

One-time bootstrap for the ChatGPT → Apple Shortcuts → Microsoft Edge execution bridge.

1 · Create the Shortcut

Open new Shortcut editor

Apple supports shortcuts://create-shortcut to open a blank Shortcut editor. iOS does not expose a supported URL parameter for injecting the entire action graph, so the action list below is the one-time manual trust boundary.

Execution protocol

After installation, ChatGPT jobs are JSON copied to the clipboard, then the bridge invokes:

shortcuts://run-shortcut?name=1JGM%20Edge%20Operator&input=clipboard
